# 华为云账号与 SWR 教程

面向希望把自己的容器镜像放进国内镜像库的用户。默认使用中文，按用户已完成的步骤继续，给出当前页面应填的字段、命令执行位置和成功标志。

## 使用方式

先读 [操作教程](references/tutorial.md)。账号注册、组织授权与凭据是基础部分；Docker、GitHub Actions、K3s 按用户实际环境选读。排查失败时读教程末尾的故障表。

- 先确认中国站或国际站、SWR 基础版或企业版、区域、镜像组织、构建环境与拉取环境。从会话或配置中已有的信息继续，不重复索要。
- 开始新接入时复核教程内官方链接的当前内容。页面、价格、配额、IAM 新旧平面和登录方式可能变化，说明核验日期。
- 注册、验证码和实名认证由用户在官方页面完成。协助配置时沿用当前操作授权；写教程本身不授权创建云资源或改线上集群。
- 根据控制台实际登录方式选择授权路径。通用型可使用 SWR 本地组织授权；增强型只支持 IAM 权限，不能照搬本地授权步骤。
- 教程中的账号名、组织、区域和 namespace 都是示例。替换整组参数，镜像端点以控制台显示值为准。
- 凭据只在本地终端、官方控制台或相应 Secrets 中输入。不让用户把 AK/SK、登录密码或完整登录指令发到聊天，不将其写进 skill 或 Git。
- CI 和集群使用各自凭据。推送用户需要目标组织/镜像的编辑权限；集群拉取用户只需要读取权限。检查是否已有更广的 IAM 授权导致限权失效。
- 完成时区分已验证的推送、下载、Pod 启动与尚未执行的示例。教程校验不等于云端实测。
- 遇到网络或权限错误，根据实际错误继续诊断。修改现有 registry mirror、重启 K3s、删除 Secret 或重跑业务 Job 需要符合用户本次授权范围。

## 验收

使用不可变 tag 或 digest，确认 CI 的推送结果、SWR 中的版本以及部署清单指向同一镜像。K3s 验证应通过使用同 namespace 拉取 Secret 的 Pod，并读取相关事件；Docker 登录成功和 registry 根路径可访问不足以证明镜像层下载成功。

## 本项目经验的适用范围

此前 daily-brief-job 使用过北京四基础版端点、通用型长期凭据、CI 编辑用户、K3s 读取用户以及 Docker media types 导出。这是已有接入的示例，不能据此断定所有区域、账号、架构或 SWR 版本都需要相同配置。Argo CD 的 Git 凭据与集群的镜像拉取凭据分别配置。
